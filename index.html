GitHub sync settings

Bills will be saved to a JSON file in a GitHub repository, so the same list shows up on every device. You need a private GitHub repo and a Personal Access Token first.

How to get a token (one-time setup)

1. On GitHub, create a new private repository (e.g. "print-house-bills").
2. Go to Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
3. Under "Repository access", choose Only select repositories and pick the one you just made.
4. Under "Permissions → Repository permissions", set Contents: Read and write.
5. Generate the token and paste it above. Keep it private — don't share this page's link or the token with anyone else.
